Project: TV Quiz

Requirements only. Build it, then tick each one when it works.

Brief

Build a quiz game for the TV. Users pick a category, answer timed multiple-choice questions, see their score and compare it on a leaderboard, using only the remote.

Targets: Android TV and Apple TV (native app), LG webOS and Samsung Tizen (web build), all from one codebase.

Data: Questions, scores and the leaderboard come from a mock API that you create. No real backend is needed.

Rule: a requirement counts as done only when it works on every target and is checked on a real TV where possible.
